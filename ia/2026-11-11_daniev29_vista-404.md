# Diseño y centrado de la vista 404 con Tailwind CSS

**Fecha:** 2026-11-11
**Integrante:** Daniel Ayala (@daniev29)
**Herramienta y modelo:** Gemini
**Archivos afectados:** `404.html`

## Objetivo
La rúbrica exige tener un estado o página para "contenido no encontrado". Creé el archivo `404.html` con un título gigante y un botón para volver al dashboard, pero necesitaba ayuda para centrar todo perfectamente en el medio de la pantalla usando clases utilitarias de Tailwind, ya que el contenido se me quedaba pegado arriba a la izquierda.

## Conversación (texto completo, sin editar)

### Prompt 1
Gemini, estoy haciendo la página de error 404 para mi proyecto. Tengo un div con un h1 que dice "404", un párrafo y un enlace `<a>` para volver al inicio. Quiero que todo este bloque quede perfectamente centrado tanto vertical como horizontalmente en la pantalla usando Tailwind CSS. ¿Qué clases le tengo que poner a la etiqueta `<body>` para lograr esto?

### Respuesta 1
Para centrar todo perfectamente en el centro de la pantalla usando Tailwind, la mejor técnica es usar Flexbox y asegurarte de que el `<body>` ocupe todo el alto de la ventana del navegador. 

Aplica estas clases a tu etiqueta `<body>`:
`class="flex min-h-screen flex-col items-center justify-center bg-slate-50 text-center text-slate-800"`

- `flex flex-col`: Activa Flexbox en columna.
- `min-h-screen`: Fuerza al body a ocupar al menos el 100vh (todo el alto visible).
- `items-center justify-center`: Centra horizontal y verticalmente.
- `bg-slate-50 text-center`: Le da el fondo gris claro y centra el texto internamente.

### Prompt 2
Genial, eso centró todo el bloque. Ahora, el botón para "Volver al inicio" es una etiqueta `<a>`. Quiero que se vea igual a los botones de confirmación de nuestro proyecto: fondo verde esmeralda, bordes redondeados y que al pasar el mouse por encima (`hover`) se ponga de un verde más oscuro. ¿Qué clases le aplico al enlace?

### Respuesta 2
Para estilizar un enlace como un botón sólido con los colores esmeralda de tu paleta y un efecto hover, puedes usar esta combinación de clases en tu etiqueta `<a>`:

`class="mt-8 inline-block rounded-lg bg-emerald-700 px-6 py-3 font-semibold text-white transition hover:bg-emerald-800 focus:outline-none focus:ring-2 focus:ring-emerald-500 focus:ring-offset-2"`

- `inline-block`: Necesario en los enlaces para que respeten el padding y el margin vertical (`mt-8`).
- `bg-emerald-700` y `hover:bg-emerald-800`: Dan el color base y el cambio al pasar el mouse.
- `transition`: Hace que el cambio de color sea suave.

## Qué se incorporó al proyecto
- Utilicé la lógica de `flex` y `min-h-screen` sugerida en la primera respuesta para el `<body>` de mi archivo `404.html`.
- Le apliqué las clases utilitarias al botón `<a>` para mantener la coherencia visual con el resto de la interfaz (botones verdes).

## Verificación
Creé el archivo `404.html`, le pegué las clases de Tailwind sugeridas y levanté el servidor con `npm run dev`. Entré a la ruta manualmente (`http://localhost:5173/404.html`) y verifiqué que en versión móvil y de escritorio el texto de "Página no encontrada" se mantiene perfectamente centrado en el eje X e Y, y el enlace redirige al dashboard.
