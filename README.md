copie este repositorio o descargue los archivos en su computador 
abra una terminal(consola) y vea hasta la carpeta principal
instale las dependencias necesarias como Vite poniendo el siguiente comando
npm install
una vez instalada ejecute este comando en la terminal
npm run dev
le mostrara un enlace local ejemplo http://localhost:5173
vistas disponibles de la pagina:
Login: Pantalla de inicio de sesión.
Registro: Pantalla para crear una nueva cuenta.
Selección de equipos (partido.html): Vista inicial para buscar los equipos a jugar.
Acta del partido (partidos.html): Formulario principal con recolección de datos (goles, tarjetas, incidencias).
